Documentos de planificación del sistema administrativo y financiero para la empresa de alquiler, venta y taller de vehículos (Guatemala).

| — | [sprints.json](sprints.json) | **Fuente única** del reparto de historias por sprint y equipo; de aquí se generan las tablas de `PlanMVP.md` y los PDF ([cómo](../herramientas/README.md)) |

| `user-stories/` | `E01-…md` a `E10-…md` | Historias de usuario con criterios de aceptación y dependencias, un archivo por épica |
